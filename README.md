# ShadowPath-review

Фокусированный review-пакет текущего R1-пролога Shadow Path.

Начните с [REVIEW_GUIDE.md](REVIEW_GUIDE.md), затем изучите материалы в [review-package](review-package/).

В пакете есть исходники, игровая логика, тесты, production-документы и мобильные visual previews. Полный локальный архив со всеми выбранными файлами подготовлен отдельно.
