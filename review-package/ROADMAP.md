# Shadow Path — roadmap

Обновлено: **20 июля 2026**.

Новая стадия начинается только после того, как предыдущая работает на реальном
iPhone. Игра остаётся портретной; local saves, существующие IDs и подтверждённый
баланс сохраняются.

## Текущий статус

Production R1 реализован для пролога. Web-проверки и подписанная iOS-сборка
проходят; сборка установлена и успешно запущена поверх существующего приложения
на `Nikita iphone` без удаления контейнера данных. Старый pre-R1 сейв сохранён,
а его ключевые инварианты после запуска совпали с резервной копией. Полный
device gate ожидает hands-on подтверждения и прохода пролога пользователем.

## R0 — безопасность и предпроизводство

Статус: **завершено**.

- [x] Зафиксированы инварианты save shape, IDs, маршрутов и баланса.
- [x] Утверждён Journey flow v2.
- [x] Утверждён unified encounter shell.
- [x] Создан production-контракт пролога.
- [x] Исторические дубли, отклонённые прототипы и неиспользуемые ассеты
  удалены; канонические документы сведены.

## R1 — новый прологовый shell

Статус: **реализовано; device QA в работе**.

- [x] Fork, destination-card route choice, travel, arrival, completion и
  evening state работают в новом Journey.
- [x] Point event, story, memory, lockpicking, battle и resolution работают в
  одном закрываемом и возобновляемом shell.
- [x] Старый UI остаётся fallback за пределами `silent-ruins`.
- [x] Не добавлены поля `GameSave`; node/encounter/minigame IDs не изменены.
- [x] `npm test`, `npm run lint`, `npm run build`, `npx cap sync ios` и
  подписанный `xcodebuild` проходят.
- [x] R1 установлен поверх pre-R1 приложения без удаления local data.
- [x] Запустить приложение на разблокированном `Nikita iphone` и структурно
  подтвердить неизменность старого сейва вне пролога.
- [x] По первым device-скриншотам добавить `Карта пути`, смысловые силуэты
  направлений и исправить safe area заголовка локальной карты; повторно собрать,
  установить и запустить патч на `Nikita iphone`.
- [ ] Проверить pre-R1 сейв на незавершённых point/story/lock/battle фазах.
- [ ] Пройти полный пролог на устройстве, включая close/resume, safe areas,
  длинный текст, три pins, memory и поле `5×5`.
- [ ] Исправить только дефекты, найденные этим проходом, и повторить gate.

## R2 — следующий вертикальный экран

Статус: **заблокировано R1 device gate**.

После R1 выбрать ровно один следующий экран и провести его через references,
wireframe, visual, states и device approval. Кандидаты:

- лагерь;
- герой и становление;
- локальная карта — предварительное направление: более схематичная
  пергаментная подача и выразительные графические точки;
- карта мира;
- хроника/профиль.

## R3 — перенос остального контента

Статус: **не начато**.

- Последовательно переносить утверждённый shell на остальные локации.
- Сохранять старый UI как fallback до принятия каждого нового экрана.
- Не добавлять поздним прототипным регионам новый канон без обсуждения.

## R4 — удаление legacy UI

Статус: **не начато**.

- Удалять старые модалки и экраны только после покрытия всех их сценариев.
- Перед удалением проверять загрузку старых сейвов и восстановление каждой
  незавершённой фазы.
- Финально проверить поддерживаемые iPhone/iPad в portrait.

## Работающий фундамент

- HealthKit steps и повторная синхронизация при возврате в приложение.
- Capacitor Preferences и old-save-safe normalization.
- Локальные ветвящиеся карты, carry-over шагов и глобальный мир.
- Point events, memories, lockpicking, connect-3, награды и abilities.
- Эволюция `Нечто → Shadowborn → Гуль` и первый осколок пролога.
- Лагерь, ночные события, журнал, streak и локальные уведомления.

## Обязательная проверка gameplay-изменений

```bash
npm test
npm run lint
npm run build
npx cap sync ios
```

После этого — подписанный `xcodebuild`, установка поверх существующего
приложения и проверка на реальном iPhone.
